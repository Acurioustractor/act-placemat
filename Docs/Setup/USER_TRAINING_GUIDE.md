## 🚀 **Quick Start - 5 Minutes to Power User**

### **Step 1: Access the Platform**
1. Open your browser to `http://localhost:5173`
2. You'll see the new navigation with **Business Agent v3** and **CRM System v3** tabs
3. The server is running on `http://localhost:4000` with all APIs active

### **Step 2: Try the Business Agent**
1. Click on **🤖 Business Agent v3**
2. In the chat interface, try these queries:
   ```
   What's my current BAS status?
   Are there any grants I should apply for?
   How are my projects performing?
   What compliance tasks are due?
   ```
3. Explore the other tabs: **Monitoring**, **Compliance**, **Grants**, **Projects**

### **Step 3: Explore the CRM System**
1. Click on **🏢 CRM System v3**
2. Browse your 20,398 LinkedIn contacts with advanced filtering
3. Click on any contact to see detailed intelligence
4. Try the **🤖 AI Enrich** button on a contact
5. Explore **Project Matching** and **Outreach Strategy** features

## 🚨 **Troubleshooting - Common Issues**

### **Server Not Responding**
```bash
# Check if server is running
curl http://localhost:4000/api/health

# Restart server if needed
cd apps/backend && node server-v3.js
```

### **Frontend Not Loading**
```bash
# Check if frontend is running
curl http://localhost:5173

# Restart frontend if needed
cd apps/frontend && npm run dev
```

### **API Errors**
- **500 errors**: Check server logs for Anthropic API key issues
- **404 errors**: Verify endpoint URLs match v3 API structure
- **Database errors**: Ensure Supabase connection is active

### **Contact Intelligence Issues**
- **No intelligence scores**: Run the data population script
- **Enrichment failures**: Check Anthropic API key and model availability
- **Missing contacts**: Verify LinkedIn data import completed
