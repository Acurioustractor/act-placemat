### Step 3: Import Contacts to GHL

**Import Process**:

1. **Export from Supabase** (already done!)
   - `goods-all-contacts.csv` has all 64 contacts with alignment scores

2. **Enhance CSV for GHL Import**
   - Add custom fields (goods_category, goods_priority_score, goods_strategic_role)

3. **Import to GHL**
   - Map CSV columns to GHL contact fields
   - Assign contacts to appropriate pipelines based on category

**CSV Enhancement Script**:
```bash
# Add GHL custom fields to CSV
cd "/Users/benknight/Code/ACT Placemat/apps/backend"

# Create enhanced CSV with GHL fields
npx tsx -e "
import { createClient } from '@supabase/supabase-js';
import fs from 'fs';
import { config } from 'dotenv';

config({ path: '../../.env' });

const supabase = createClient(
  process.env.SUPABASE_URL,
  process.env.SUPABASE_SERVICE_ROLE_KEY
);

async function exportForGHL() {
  const { data: contacts } = await supabase
    .from('linkedin_contacts')
    .select(\`
      *,
      project_contact_matches!inner(
        alignment_score,
        match_reason,
        project_name
      )
    \`)
    .eq('project_contact_matches.project_name', 'Goods.');

  const ghlCSV = contacts.map(c => ({
    first_name: c.first_name,
    last_name: c.last_name,
    email: c.email_address,
    company: c.current_company,
    position: c.current_position,
    linkedin_url: c.linkedin_url,
    goods_priority_score: c.project_contact_matches[0].alignment_score,
    goods_category: getCategoryFromTags(c.alignment_tags, c.current_company),
    goods_strategic_role: c.project_contact_matches[0].match_reason,
    alignment_tags: c.alignment_tags?.join(', '),
    phone: c.phone_number || '',
    goods_outreach_status: 'Not Contacted',
    goods_next_action: getNextAction(c),
    bio: c.bio || ''
  }));

  const csvContent = [
    Object.keys(ghlCSV[0]).join(','),
    ...ghlCSV.map(row => Object.values(row).map(v => \`\\\"\${v}\\\"\`).join(','))
  ].join('\\n');

  fs.writeFileSync('../../goods-ghl-import.csv', csvContent);
  console.log('✅ Created goods-ghl-import.csv for GHL import');
}

function getCategoryFromTags(tags, company) {
  if (!tags) return 'Other';
  if (tags.includes('health')) return 'Health';
  if (tags.includes('legal')) return 'Legal';
  if (tags.includes('funding') || tags.includes('philanthropy')) return 'Funder';
  if (tags.includes('indigenous')) return 'Indigenous';
  if (tags.includes('research') || tags.includes('academic')) return 'Academic';
  if (tags.includes('media') || tags.includes('storytelling')) return 'Media';
  if (tags.includes('product') || tags.includes('manufacturing')) return 'Product';
  if (company?.includes('Wilya Janta')) return 'Indigenous';
  return 'Other';
}

function getNextAction(contact) {
  const category = getCategoryFromTags(contact.alignment_tags, contact.current_company);

  const actionMap = {
    'Indigenous': 'Schedule Beautiful Obsolescence planning meeting',
    'Health': 'Email research partnership proposal',
    'Legal': 'Request pro bono consultation',
    'Funder': 'Research funding priorities and application process',
    'Academic': 'Email academic partnership proposal',
    'Media': 'Brief on Goods. story and Beautiful Obsolescence narrative',
    'Product': 'Schedule optimization and partnership review',
    'Customer': 'Request feedback and explore expansion'
  };

  return actionMap[category] || 'Research and develop outreach strategy';
}

exportForGHL();
"
```

### Step 5: Create Workflows (Automations) in GHL

**Workflow 1: Beautiful Obsolescence Automation**

**Trigger**: Contact added to "Beautiful Obsolescence" pipeline, Stage 1

**Actions**:
1. Wait 1 day
2. Send "Beautiful Obsolescence Intro" email
3. Wait 3 days
4. If no reply: Send follow-up email
5. If reply: Move to Stage 2 "Discovery Call Scheduled"
6. Wait 7 days
7. If still no reply: Send final follow-up + LinkedIn message
8. If still no reply: Move to "Inactive" stage

**Workflow 2: Meeting Scheduled Automation**

**Trigger**: Contact moves to "Discovery Call Scheduled" stage

**Actions**:
1. Send meeting confirmation email with Zoom link
2. Send meeting prep document
3. Add to calendar
4. Wait until 1 day before meeting
5. Send meeting reminder email
6. Wait until 1 hour before meeting
7. Send meeting reminder SMS (if phone number available)

**Workflow 3: Post-Meeting Follow-Up**

**Trigger**: Meeting completed (manual trigger or calendar event)

**Actions**:
1. Wait 1 hour
2. Send thank you email with meeting notes
3. Send action items list
4. Create tasks for follow-up actions
5. Schedule next check-in (2 weeks)
6. Move to next pipeline stage

**Workflow 4: Funding Application Follow-Up**

**Trigger**: Contact moves to "Application Submitted" stage

**Actions**:
1. Send confirmation email
2. Wait 2 weeks
3. Send gentle check-in email
4. Wait 4 weeks
5. Send decision timeline inquiry
6. If decision received: Move to "Funding Secured" or "Rejected" stage

**Workflow 5: Inactivity Re-Engagement**

**Trigger**: Contact has no activity for 30 days

**Actions**:
1. Send re-engagement email with project update
2. Wait 7 days
3. If no reply: Send LinkedIn message
4. Wait 7 days
5. If no reply: Move to "Inactive" stage

## 🔗 Integration with ACT Ecosystem

### Connection 1: Supabase → GHL Sync

**Purpose**: Keep GHL contacts in sync with Supabase enrichment data

**Implementation**:
```javascript
// Webhook endpoint: /api/ghl/sync-contact
// Triggered when: Contact enriched in Supabase

app.post('/api/ghl/sync-contact', async (req, res) => {
  const { contactId } = req.body;

  // Get enriched contact from Supabase
  const { data: contact } = await supabase
    .from('linkedin_contacts')
    .select('*')
    .eq('id', contactId)
    .single();

  // Update GHL contact
  await ghl.updateContact(contact.email_address, {
    linkedin_url: contact.linkedin_url,
    bio: contact.bio,
    current_position: contact.current_position,
    // ... other enriched fields
  });

  res.json({ success: true });
});
```
